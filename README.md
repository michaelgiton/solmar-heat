Solmar Heat — a 3D open-world crime game in the coastal city of Solmar. Maya Reyes drives for her uncle Theo's garage: 6 story missions, stealable cars, traffic and pedestrians, a 0–5 star wanted level with police pursuit, combat, and a full HUD with minimap. No build step; static files under game/.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
